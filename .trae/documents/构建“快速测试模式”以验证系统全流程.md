# ⚡️ 快速测试模式 (Fast Test Mode) 实施计划

为了满足您快速验证系统流程、无需等待且节省 Token 的需求，我将为系统添加一个全局的 **`FAST_TEST_MODE`**。

## 1. 核心配置 (Configuration)
在全局配置中引入开关，方便您随时一键切换测试/生产环境。

*   **修改 `config.py`**:
    *   添加 `FAST_TEST_MODE` (bool) 字段，默认从环境变量读取，缺省为 `False`。
*   **修改 `.env`**:
    *   添加 `FAST_TEST_MODE=True`，开启测试模式。

## 2. 极速版 Agent (Fast Agents)
当测试模式开启时，我们将“短路”三个分析引擎的核心逻辑，直接返回预设的简短结果，跳过所有耗时的搜索、反思和 LLM 调用。

*   **涉及文件**:
    *   `QueryEngine/agent.py`
    *   `MediaEngine/agent.py`
    *   `InsightEngine/agent.py`
*   **修改逻辑**:
    *   在 `run` 或入口方法处检查 `settings.FAST_TEST_MODE`。
    *   **若开启**:
        *   将 `MAX_REFLECTIONS` 强制设为 0（禁止循环反思）。
        *   跳过 `SearchNode` 和 `AnalysisNode`。
        *   直接生成一段约 50 字的模拟数据（例如：“[测试模式] QueryEngine 已收到请求，这是一段模拟的搜索结果...”）。
        *   确保将结果正确写入 `state` 和日志，以便 ReportEngine 能够读取。

## 3. 极简报告模板 (Mini Report)
为了让报告生成也瞬间完成，我们将强制使用一个极简的 Markdown 模板，跳过复杂的模板选择逻辑。

*   **新建文件**:
    *   `ReportEngine/report_template/FastTestTemplate.md`: 一个只有标题和摘要的 100 字模板。
*   **修改逻辑 (`ReportEngine/nodes/template_selection_node.py`)**:
    *   检查 `settings.FAST_TEST_MODE`。
    *   **若开启**: 忽略 LLM 智能选择，直接锁定使用 `FastTestTemplate.md`。

## 4. 预期效果
完成修改后，您的测试流程将变为：
1.  **启动**: 设置 `.env` 中 `FAST_TEST_MODE=True`。
2.  **提问**: 输入任意问题（如“测试流程”）。
3.  **响应**:
    *   三个 Agent **几乎瞬间**完成（< 3秒），不消耗搜索 API 和 LLM Token。
    *   Report Agent **立即**生成一份仅包含三个 Agent 模拟回复的简报。
4.  **耗时**: 从提问到报告生成，预计总耗时 **< 10秒**。
